# VSL
The vector support library.

## Math
- `abs`
- `trunc`, `floor`, `ceil`, `round`
- `fmod` (also `wrap`)
- `cos`, `sin`, `tan`
- `cos_2pi`, `sin_2pi`
- `acos`, `asin`, `atan` (Padé approximants)
- `exp`, `exp2`
- `log`, `log2`, `log10` (also `logB`)
- `pow` (for bases >= 0)
- `cosh`, `sinh`
- `tanh` (Padé approximant)
- `min`, `max`
- `clamp`
- `sign`
